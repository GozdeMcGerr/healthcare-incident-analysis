# Healthcare Incident Analysis (2017–2024)

## Overview

This project analyses attacks and threats against healthcare workers and healthcare infrastructure using publicly available World Health Organization (WHO) data.

The analysis examines attack types, locations, perpetrators and trends between 2017 and 2024 to identify patterns and support evidence-based recommendations for protecting healthcare services in conflict-affected regions.

## Business Objective

The aim of this project was to:

- Identify trends in attacks on healthcare services
- Analyse regional hotspots
- Examine weapon types and attack methods
- Explore the impact on healthcare workers and facilities
- Provide recommendations to support healthcare system resilience

## Tools Used

- Excel
- SQL
- Pivot Tables
- Data Visualisation
- Trend Analysis

## Key Findings

- Conflict-related violence accounted for 99% of recorded incidents
- The Gaza Strip represented 54% of attacks
- Aerial bombs were the most common weapon type
- Health buildings were the most frequently targeted location
- Large spikes in incidents were observed during 2018 and 2023
